# FDE Program Practice

Code for the FDE Program course, week by week, from week 5 onwards.

Each `week-NN/` folder has:

- `final/` — the finished code for that week.
- `in-class/` — where the instructor codes live during the session.

## How to use

This repo is read-only for students. Clone it and work locally:

```bash
git clone https://github.com/shahhassan24/FDE-Program-Practice.git
cd FDE-Program-Practice
git pull   # each week, to get new code
```

To keep your own work on GitHub, copy a week's folder into your own repository.
