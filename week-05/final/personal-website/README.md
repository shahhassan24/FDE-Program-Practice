# Personal website (Tailwind)

Example end product for the week 5 assignment: a one-page personal site styled only with Tailwind classes.

Sections: header, intro, selected work, about, contact, footer. Uses a small `tailwind.config` for colours and fonts (Instrument Serif, Inter, JetBrains Mono). "Ayesha Khan" and all links are placeholders, so swap in your own.

## Run

Open `index.html` in a browser, or use **Go Live** in VS Code. Tailwind loads from the Play CDN, so you need an internet connection.

## Test

- Nav links scroll to each section.
- Resize to phone width: the work list and about section stack into one column.
- Hover a work row: the title turns orange and the arrow slides right.
