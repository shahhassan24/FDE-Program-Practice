# Personal website (Tailwind)

Example end product for the week 5 assignment: a one-page personal site styled only with Tailwind classes.

Sections: header, intro with portrait, selected work, about, contact, footer. A small `tailwind.config` in the page sets the colours and fonts (Instrument Serif, Inter, JetBrains Mono).

"Bilal Ahmed", the email and the links are placeholders. `images/portrait.jpg` is a free stock photo from Unsplash; use your own photo.

## Run

Open `index.html` in a browser, or use **Go Live** in VS Code. Tailwind and the fonts load from a CDN, so you need an internet connection.

## Test

- Nav links scroll to each section.
- The portrait shows in black and white and turns to colour on hover.
- Resize to phone width: the intro, work list and about section stack into one column.
- Hover a work row: the title turns orange and the arrow slides right.
